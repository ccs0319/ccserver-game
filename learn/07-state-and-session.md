# 07 · 状态放哪 & 会话 / 顶号

## 你将学到

服务器里"数据放哪里"是头等大事。你会看到状态的三种归宿，以及"会话"这个贯穿始终的概念。

---

## 1. 状态有三种归宿

| 归宿 | 说明 | 例子 |
| --- | --- | --- |
| **① Actor 私有** | 只属于某个服务的内存，别人只能发消息访问 | world 的 `entities`、lobby 的会话表 |
| **② 由某服务拥有** | 有明确"主人"，谁拥有谁负责 | login 的账号表、world 的玩家实体 |
| **③ 外置共享** | 需要多个服务/多台机器共享 → 放外部存储 | 会话（Redis）、排行（Redis）、持久数据（DB） |

**判断规则：**
- 只有一个服务用 → ① 或 ②（放它自己 actor 里）。
- 多个服务/多台机器要读 → ③（外置，如 Redis）。
- 要重启后还在 → ③（DB 持久化）。

## 2. 为什么不能"全局变量"一把梭

因为**每个 actor 是独立内存**（第 3、4 篇）。你在 gateway 里设的"全局表"，
login/world **根本看不到**。硬要共享只能：
- 通过消息把数据传过去，或
- 外置到共享存储。

这看起来"麻烦"，但正是它让并发变简单：**没有共享 → 没有数据竞争。**

## 3. 会话（Session）：连接 ≠ 会话

先把两个概念分开：

- **连接（connection）**：一条 TCP。属于某个 gateway，随时可能断。
- **会话（session）**：**"这个账号现在由谁在线"** 这个事实。应该独立于连接。

为什么要分开？因为玩家可能：
- 断线重连（换了一条连接，甚至换了一个网关）；
- 在别处登录（要把旧连接踢掉，即**顶号**）。

所以**会话必须能被"跨连接、跨网关"地查询和踢除**。

## 4. Token：无状态的钥匙

登录成功后，login 发一个 **token**（比如 `account:uid:time`）。
之后玩家每次进游戏带 token，服务器**校验 token 就能知道是谁**，不需要记住"刚才发给了谁"。

- 好处：**任何网关都能校验**（token 无状态）→ 玩家重连到任意网关都行。
- 安全：token 由 login 签发和校验，gateway 不碰密钥。

## 5. 会话属主：谁在线

光有 token 还不够——服务器还要知道**"这个 uid 现在挂在哪个网关的哪条连接上"**，
才能做到"新登录踢旧登录"。

本仓库把这件事外置到共享存储（`ccserver.session`）：

```
session:<uid> = { gateway="gateway_1", node=1, zone=2, ts=... }
```

- 单机：内存后端。
- 多网关/多机：**Redis 后端**（大家都能读）。

## 6. 顶号（同一个账号登录两次）

流程（gateway 处理 ENTER 时）：

```
1. 校验 token → 得到 uid
2. 读共享会话：uid 现在归谁？
     若归【别的网关】→ router.call(那个网关, "kick", uid) 让它踢线
3. 写共享会话：uid 归【本网关】
4. 本地若已有同 uid 连接 → 也踢掉
5. 完成进入
```

- **同网关顶号**：直接踢本地的旧连接。
- **跨网关顶号**：发消息给持有旧连接的网关，让它踢（第 8 篇讲跨进程）。

## 7. 重连

玩家断线后重连：
1. 连上**任意** gateway；
2. 重新 `HELLO` + `ENTER(token)`；
3. gateway 校验 token、更新会话属主、踢掉可能残留的旧连接；
4. 恢复游戏内状态（world 里的实体还在，因为它在 world actor 里，没跟着连接走）。

> 关键设计：**玩家数据活在 world，不活在连接上。** 连接断了，数据还在。

## 8. 对应到代码

| 概念 | 文件 |
| --- | --- |
| 会话属主存储 | `lualib/ccserver/session.lua`（memory / redis） |
| 绑定/顶号/重连 | `lualib/ccserver/services/gateway.lua`（`handlers.ENTER`、`commands.kick`） |
| token 签发/校验 | `lualib/ccserver/services/login.lua` |
| 玩家实体 | `lualib/ccserver/services/world.lua` |

## 记住这句

> **状态要么归某个 actor，要么外置共享；连接 ≠ 会话；token 无状态；会话属主外置才能跨网关顶号与重连。**
